# Quartz

Turn any topic into linked articles, podcasts, and educational video prompts.
Live: [https://www.tryquartz.wiki](https://www.tryquartz.wiki)

## What it does

- Generate an article about a topic and click its linked concepts to explore related articles.
- Simplify articles for different reading levels and ask questions about their content.
- Listen to article narration or a two-person podcast conversation.
- Create educational video prompts and test your understanding with multiple-choice quizzes.

400+ articles generated by users since January 2026.

## How it works

Enter a topic and Quartz checks its Supabase cache before asking OpenAI to generate an article. The article streams into the page with concepts marked as links. Clicking a concept opens another article panel and repeats the same flow. Separate API routes turn article content into simpler explanations, audio, podcasts, quizzes, and video prompts.

## Tech stack

- Next.js 14, React 18, and TypeScript
- Tailwind CSS and Radix UI
- OpenAI for article generation, chat, speech, and transcription
- Supabase for authentication, content caching, and audio storage
- Stripe for subscriptions
- KaTeX for math rendering
- Vercel Analytics

## Run locally

Install Node.js and npm, then clone this repository and enter its directory.

Create `.env.local` with your own values for:

- `OPENAI_API_KEY`
- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`
- `SUPABASE_SERVICE_ROLE_KEY`

For caching and usage tracking, set up the Supabase tables referenced in `src/lib/server-cache.ts` and `src/lib/usage.ts`, plus the `quartz-audio` Storage bucket. SQL setup scripts are not included in this repository.

```bash
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
For a production build, run `npm run build`, then `npm start`. Run `npm run lint` to check the code.
Subscriptions also require `STRIPE_SECRET_KEY`, `STRIPE_PRICE_ID`, and `STRIPE_WEBHOOK_SECRET`.
